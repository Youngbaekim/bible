# 원어 단어 분석 데이터

- 출처: STEPBible Data (Tyndale House, Cambridge) — TAHOT(히브리어 구약), TAGNT(헬라어 신약)
  https://github.com/STEPBible/STEPBible-Data  · 라이선스 CC BY 4.0 (www.STEPBible.org)
- 변환: 책별 JSON. `v["장:절"] = [[원문, 음역, 영어 뜻, 스트롱, 문법코드, 원형, 원형 뜻], ...]`
  - 히브리어는 히브리어 성경 절 번호 기준(앱의 히브리어 본문과 동일). `e`에 한글·영어 성경 절 번호 대응.
  - 헬라어는 SBL 판에 있는 단어만 포함.
